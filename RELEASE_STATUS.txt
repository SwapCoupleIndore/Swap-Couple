SWAP COUPLE — BREVO EMAIL OTP / NO-SMS RELEASE
Build date: 2026-11-19

Changes in this package:
- Email OTP uses Brevo HTTPS Transactional Email API.
- SMTP delivery and all MSG91 integration code/configuration/UI are removed.
- Mobile number remains a required registration field and is displayed in the owner dashboard; it is not OTP-verified.
- Email verification and private selfie submission are required before owner approval.
- Admin approval requires verified email, submitted selfie, and an unblocked account.
- Existing phone_ok database column is retained for compatibility with the existing database, but it is no longer used for authorization, approval, or chat.
- Existing user records and admin account are not deleted or reset.
- PostgreSQL binary image storage, private selfie access, registration age validation, login throttling, chat, meeting and existing profile workflows are retained.
