IMPORTANT LIMITATIONS - NOT A PRODUCTION CERTIFICATION
1. MSG91 OTP Widget is NOT integrated. The app currently uses an HTTPS SMS webhook adapter. The configured widget ID alone is not enough: its Widget Token and server-side Authkey/JWT verification configuration are needed. Never put the Authkey in browser JavaScript or share it in chat.
2. `init-db` uses SQLAlchemy `create_all()` for a fresh installation. It is not a versioned schema migration system and will not update existing tables.
3. Flask dependencies were not available in the build environment, so Flask import, database, route, SMTP, MSG91, S3, browser, and end-to-end runtime tests were NOT run.
4. Render/PostgreSQL, Brevo SMTP, MSG91, and S3/R2 credentials and live service configuration are not included. They must be configured as private environment variables in the provider dashboards.
5. Do not deploy this build as production-ready until the above integrations and runtime/security tests have passed.

PRODUCTION ENVIRONMENT VARIABLES EXPECTED BY CURRENT APP
SECRET_KEY (>=32 chars), DATABASE_URL, ADMIN_EMAIL, ADMIN_PASSWORD (>=12 chars),
PUBLIC_BASE_URL (https://...), SMTP_HOST, SMTP_PORT (normally 587), SMTP_USERNAME,
SMTP_PASSWORD, SMTP_FROM, SMS_WEBHOOK_URL (https://...), SMS_WEBHOOK_TOKEN,
S3_BUCKET, S3_ENDPOINT_URL, S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY, S3_REGION.
